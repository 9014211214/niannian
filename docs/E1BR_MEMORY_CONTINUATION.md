新活动仅执行余325个基本位置：312在线、6memory、7reflection。第一新位置为e1/S2 reflection，只使用原会话、失败后实际保存的资料、旧人物假设及其证据；不把坏memory正文变成事实或人物证据，不回滚此前成功资料，不改原会话时间或延长保留期。

固定1056基本位置、216回复评分位置、12题形成分母。缺失、格式失败、实际规则兜底、保护改写及原模型答复分别记录。模型盲包只含有依据且可导出的现有位置；不凭固定分母虚构216条有效模型标签。

该memory仍为failed，候选与接受数为null，memory_completed为false，单独保留缺失审计。没有记忆更新，不修补正文，不收费重答或增加memory格式更正。后续reflection是独立职责，仍审核原会话。未来同类memory语法失败采用同一窄规则；合法JSON的语义/证据拒收、拒答、未读全、未知费用、运输/保存故障不因此放行。生产护理与普通会后队列的规则不变。
