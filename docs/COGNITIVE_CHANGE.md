# C1 设计：记忆与日常变化提醒（不诊断）

状态：**C1-A 语义审阅与隐私传递已实现（20261006-04，v4）**；新软件证据不继承旧 C-test 的模型结论。最新验收和未完成项只看 [PROGRESS](PROGRESS.md)。

## 1. 定位与用户决定

用户 2026-10-02 决定现在就做，并明确目标：“不是要诊断，是提醒，我们不能代替医生做诊断。”

**这个功能做什么**：老人本人开启后，Aria 留意他在聊天中**自己说出的**记忆和日常变化，并和他自己的过去比较。
变化持续出现时，Aria 只对他本人温和地说出观察，问他愿不愿意找医生聊聊，并可以帮他设一个由他自己掌控的提醒。
告不告诉家人，由他决定。

**这个功能不做什么**：

- 不判断是否患病；
- 不给分数、概率或风险等级；
- 不说病名，包括“痴呆”“阿尔茨海默”“认知障碍”；
- 不出测试题（如 MoCA）；
- 不分析声音；
- 不替他通知家人。

这与产品主线一致：本人确认、可以纠正、由他决定、只转达他同意的内容。

**对外措辞**：用“记忆与日常变化提醒”“留意变化”，不用“识别”“筛查”“预防阿尔茨海默”。
商用之前，要另行确认是否落入医疗器械软件的监管范围。

## 3. 信号（只来自文字，只看本人说的话）

会后 memory 步骤**在同一次调用里**审阅已同意本人原话区的全部轮次，额外提出 `cognitive_observations`，不增加调用次数。
采集和领域准入不要求出现特定词；是否属于变化、领域及实际日常影响由模型提出。每条观察都必须带逐字本人原话，由代码核对出处、本人同意、时间、重复事件及明确负向边界，校验不过就丢弃。逐字匹配只证明说过这段话，不能证明语义分类正确。

同一响应还必须有 `cognitive_privacy` 数组，元素为 `turn_index` 与逐字 `evidence_quote`。它仅用于阻止认知隐私进入普通事实、相处说明和人物分析；未开启 C1 也做此排除，但不采集认知观察、不累计趋势。空数组表示完成审阅后无此类标注，不能用缺字段代替。缺失、类型错误或无效原话使本次 memory 失败，未筛查的会话不能继续给真实 reflection。

| 领域 | 例子 | 不算 |
| --- | --- | --- |
| memory 记事 | “我又想不起钥匙放哪儿了”“刚吃没吃药我记不清了” | 偶尔说“老了记性差”这类泛泛自嘲（记为 context，不计数） |
| language 找词 | “那个东西叫啥来着，话到嘴边说不出” | 方言、口误 |
| orientation 时间地点 | “今天礼拜几我都搞混了” | 突然不认得家、迷路回不来 → **急症路径**，不进入趋势 |
| daily_function 日常事务 | “这个月忘了两次交电费” | 忘关火、重复吃药 → **安全提示优先**，不进入趋势观察 |
| repetition 重复 | 同一会话内第三次问同一个问题且没意识到；7 天内在 3 个不同会话里像第一次那样讲同一件事 | 老人有意重讲往事（“我跟你说过吧，再说一遍”） |

`repetition` 依赖已有的 same_event 事件链，只在模型和代码都确认是同一事件时才计数。

护理模块里的“提醒未确认”**不作为信号**，因为“未确认”不等于忘记。

## 4. 状态规则（工程规则，不是临床标准；阈值写入登记后才改）

```
disabled ─本人开启─▶ calibrating ─满 14 天且 ≥ 6 次会话─▶ watch ─满足提醒条件─▶ review_suggested
   ▲                                                       ▲                       │
   └──────────────── 本人关闭（询问是否删除记录）──────────┴── 本人说“不用” / 已设提醒 ┘
```

- **提醒条件**（任一满足）：
  - 最近 30 天里，观察来自 ≥ 3 个不同自然日、≥ 2 个领域，且数量明显多于校准期（例如校准期每周 ≤ 1 条，现在每周 ≥ 2 条）；
  - 带 `functional_impact` 的观察来自 ≥ 2 个不同自然日。
- **冷却**：本人说“不用”后 30 天内不再提起；第二次说“不用”后冷却改为 90 天。他主动问起时随时可以谈。
- **校准期**：不提醒，只记录，这样“和他自己比”才有基线。
- 状态和观察只给本人看，在透明面板中列出原话，可以逐条删除。

## 5. 在线怎么说

- 只在状态为 review_suggested 时，在线提示中加入一个数据块：“可以温和提起的观察（本人原话）”。
- **时机**：会话开头的寒暄之后，而且外部情绪读数和当轮表达都不是低落或生气、他没有在办事或求助时才提；本轮不合适就留到下次。
- **怎么说**（写进提示的约定，并由护栏兜底）：
  1. 用他自己的话说出观察：“这个月你有几次说起想不起东西放哪儿了。”
  2. 不评价、不说病名：“不一定说明什么，年纪大了也常见。”
  3. 给可以拒绝的选择：“下次体检时要不要跟医生提一句？要的话我帮你记个提醒。”
  4. 他决定之后就停止，不再劝。
- 他问“我是不是老年痴呆了”时：如实说明 Aria 判断不了，只有医生能判断；问他是否想去看看；不安慰说“肯定没事”，也不吓他。
- 他问怎么保持脑子好用时：只给公认的一般建议，来自预先审定的短清单，比如多和人来往、规律活动、管好血压、听力不好及时处理，不宣称能预防。
- **家人**：只有他明确说“告诉我闺女”，并且走现有的授权流程，才能转达，而且只转达他同意的那一句。

## 6. 和其他部分的关系

- **与 R1**：本人要求不再主动提起时，由 C1 的关闭或冷却状态控制；相关敏感原话不写入普通相处说明。本人主动问起时可以回应，但不自动恢复观察或授权。
- **与人物假设**：认知观察永远不进入人格假设，现有测试保持。
- **与 EM-1**：外部情绪读数只用来判断“现在适不适合提”，不作为认知信号。
- **与 E1b**：C1 默认关闭，旧 E1b 不采集认知观察。v4 通用 memory 增加语义隐私排除协议，所以不能说新提示与旧实验逐字不变，也不能继承旧实跑效果。
- **故事**：陈师傅最近几次说起忘了和外孙女约好的事。几周后，Aria 在他心情好的时候提起，他说“我自己跟闺女讲”。Aria 只帮他记了个体检时问医生的提醒，没有通知任何人。

## 7. 验收

**本地，0 费用：**

1. 授权：默认关闭；只有本人能开启（护理员不能代开）；关闭时询问是否删除记录。
2. 信号：原话不逐字匹配就丢弃；泛泛自嘲不计数；急症句走紧急路径且不进入趋势；护理“未确认”不计数。
3. 状态：按第 4 节规则做边界测试，校准期内从不提醒，冷却期生效。
4. 在线：只在 review_suggested 且时机合适时出现数据块；关闭或冷却时提示逐字节不变。
5. 护栏：任何回复都不出现病名、分数、概率（复用并扩充现有测试）。
6. 分享：没有授权时，任何转达草稿都不含认知观察。
7. 透明：面板显示原话，可以逐条删除。

**以下为旧C-test登记：2026-10-03批准上限2美元，已实跑情况见进度。该授权不自动延伸到审计后的C-test v3。**

- 我编写 12 个虚构人物的合成多会话脚本：6 个有逐渐增多的变化，6 个对照（只有正常的偶尔忘事）。每人 8 次会话、每次 10～12 轮。
- 走真实会后模型，看提醒是否被触发。
- **对照组误触发必须为 0**，有变化组至少 4/6 触发；所有回复都通过护栏检查。
- 原估计 96 次会后调用、约 1.5～2 美元；2026-10-03 已获上限 2 美元授权，实际按完整请求核算。
- 结果只说明“规则在虚构脚本上按设计工作”，不说明能发现真实的认知变化。

## 9. 本地实现约束（20261006-04 修订）

- 费用状态：旧C-test上限2美元及其真实调用、失败、费用只在 [PROGRESS](PROGRESS.md) 记录；新独立作者C-test v3须另批，本地软件测试不代替真实模型结果。
- 规则版本 `cognitive-change-v4-20261006`：至少14天且6次不同会话完成校准；校准完成时刻的观察仍属于基线。近30天的频率按会话×领域去重，至少3个自然日、2个领域，固定30天率须≥2条/周且≥基线的2倍；或校准后有功能影响的观察来自至少2个自然日。功能影响按合格原件的自然日取并集，不因同类别的后一条轻微记录覆盖前一条而丢失；重复记录不增加频率或自然日。v4不改这些阈值；旧v2/v3真实测量和新版本软件检查分开。默认自然日为 Asia/Shanghai，与护理入口一样只支持此时区或 UTC，不依赖主机时区。
- 全部已同意的当前本人原话单独封存于 `cognitive_turns`，继承普通会后任务的24小时上限及120轮限制；急症、明确不保存等仍排除。不能把这个独立原话区全都当成隐私或禁止普通事实。memory 模型的逐字隐私标注以及有效观察出处先更新排除 mask，再提取事实、关系与 R1；旧关键词仅作额外隐私兜底，不作为正向采集条件。
- memory 成功时，事实结果、排除 mask、原会话对应本人和助手轮次的清空、`memory_privacy_review_completed` 标志同次持久保存。reflection 重建筛过的原会话，看不到独立认知原话通道或观察记录，也不拿 memory 摘要替代原会话。保存失败不继续 reflection；重启后保留同一 mask。旧 LLM 任务即便已有 `memory_completed`，没有隐私完成标志也封存失败，不重新收费、不暴露未筛原文。本地纯规则整理不冒称完成模型语义审阅。
- 只采集开启之后当前说出的内容，不回读旧聊天补证据。关闭即停止采集并清空待处理的独立原话，已有观察由本人选择保留或删除；逐条删除留下不含原话的去重标识，防止旧任务复写。删除观察不会删除原聊天，界面明确区分两者。
- 首发 Web 是单个虚构人物的本机演示：本人表面固定对应该角色，护理员 API 无此操作；这不等于现实身份认证。真实老人部署的本人身份验证仍需另行设计和验收。
- 在线仅在会话寒暄之后的前3轮、当前无低落/生气/办事/求助线索，且外部读数为 calm/happy/neutral、置信度≥0.4时允许提起。缺失、未知、低置信、模拟读数均不主动触发。本人主动问起仍按普通有边界的医疗回应处理。
- C1 的授权不包含对外分享；当前首发通知范围不允许认知观察外发。相关转达草稿先停下，请本人明确选择内容和分享授权，不能把开启观察当作已授权告诉家人。
- 急症沿原确定性安全路径优先处理，不增加趋势观察。C1 开启时回复守卫同时禁止疾病名称/个人分数和概率；不改变既有医疗规则、联系人权限或护理升级阈值。

## 10. 本轮软件证据与未证明项

- 独立作者先封存的24例只用预设标签通过产品传递链，不运行模型、不测领域或功能影响分类准确率。首次结果：全部24轮可供审阅；预置应观察的12例中11例存入，12例预置不观察均未创建；17例预置隐私全部从 reflection 原会话排除，7例普通来源中6例保留。
- A05 的本人找词说法含“邻居”，被旧第三人负向兜底误拒；A21 是文章引文，含“忘”而被旧隐私兜底保守排除。首次结果与原分母保留；未据这两题调提示或负向词表。负向规则仍不完备，语义标签也可能错误；这些结果不代表自然语言理解准确率。
- 另以固定标签验证无关键词原话、普通事实继续可用、关闭与撤回、无效标注整次失败、memory 与 mask 原子保存、重启不重跑 memory、旧未审阅任务拒绝 reflection。模型真能正确识别自然表达仍需另版 C-test v3；其付费运行未获批准，旧 C-test 不能替代。
