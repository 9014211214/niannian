# C-test 会后组件实验登记

当前进度与费用以 [PROGRESS](PROGRESS.md) 为准。本文件定义 20261003-02 的前瞻规则；旧实验的分数、失败与费用不变。

## 固定范围

- 12 名虚构人物：变化组 6 人、对照组 6 人。每人 8 次会话、每次 10 轮，共 96 次 memory 调用。脚本在 `aria/bench/ctest_cases.py`，加载后另存内容 SHA。
- 使用生产 `LLMExtractor`、`MemoryConsolidator`、授权后的独立原话通道、逐字校验及 C1 状态规则。Claude Sonnet 5 通过 OpenRouter 的 Anthropic 路由；无回退、无自动重试、关闭 reasoning，输出最多 1800 tokens。
- 在线模型调用 0、reflection 调用 0、模型裁判调用 0。脚本中的助手文字是合成上下文，并非实际 Agent 回复；960 条脚本文字的护栏检查只算软件检查。
- 会话的第 0/2/4/7/10/12/18/24 天来自隔离的虚构时钟（2000 年），真实请求时间单独记录。不修改实际产品历史时间戳，不接触真实老人档案。
- 只向模型提供当前会话及实际生产抽取所需上下文，不提供未来台词、组别、预期触发结果。认知记录不得变为人格假设。

## 判定与限制

96 次会后处理均有效完成后，**对照误触发 0/6，变化至少触发 4/6**，才通过本批组件门。任一组超出预定条件就如实报告失败，不改脚本选最好结果。未完成、解析失败、结果不明或保存失败均列为不可评，保留 12 人与 96 会话分母。模型须明确返回 `cognitive_observations` 对象数组，缺字段或错误类型不能当作“观察数为零”。

本批主要覆盖“校准后两个自然日有生活事务受影响”的提醒条件；三日多领域增长条件由独立软件边界测试覆盖。本结果不验证真实老人认知变化、临床诊断、在线回应质量或完整 Engine 路径。

## 费用和停止规则

用户于 2026-10-03 同意 C-test **上限 2 美元**。此前 E1 已知 0.026719172 美元、两笔获接受但未核清的费用原样保留。为遵守原累计已知 2 美元停下报告的约定，本次有效新额度为 **1.973280828 美元**；不将未知费用算作零。

每次发送前，以实际请求 UTF-8 字节数加 8192 的输入规划余量、最大输出 token 和冻结价格做持久预留，并限制供应方报价；收到结果后核对模型、供应方、token、reasoning、finish reason 和费用。该方法是保守规划，不是供应商账单保证，也不保证 96 次能全部在预算内完成。预算不足、未知费用、新错误、回执不符或保存失败即停发，不盲重发；原始账本和公开结构化 memory 内容保留于本机忽略目录，不记录隐藏推理。

## 冻结和执行

`scripts/run_ctest.py --prepare` 不读密钥、不联网，冻结全部当前 `aria` Python 源码、执行脚本、此协议、固定分母、脚本内容、公开能力/价格原件及其采集记录的 SHA；`--verify` 在执行前复核采集来源、时间与原件哈希。公开元数据和登记超过 24 小时拒绝发送。实际线上的逐次请求还须经过独立的发送前参数校验。

只有明确 `--execute --allow-local-env` 才允许程序从本机 `.env` 提取 `OPENROUTER_API_KEY`，不导入其他变量、不输出密钥。项目内固定 `artifacts/local/tasks/20261003-02/ctest-authorization.started.json`、冻结登记旁和输出目录均保留不可覆盖的启动标记；复制登记、重新准备登记或更换输出目录都不能重置同一次费用授权。即使在首次发送前失败，也不自动清除标记；执行负责人核对零发送原件后才可修复并另行登记，有过请求的账本不能隐蔽重建。

执行记录与完整本机原件位于 `artifacts/local/tasks/20261003-02/`。最终结果须关联冻结 SHA，分别报告软件测试、真实调用数、有效会话、门结果、已知费用和未知费用；单纯 HTTP 成功不算效果通过。
