# 证据与对外表述

实际版本、验证结果、失败和未完成项只记在 [PROGRESS](PROGRESS.md)。本页固定解释证据边界，
避免把测试数量写成产品效果；旧实验和费用原件按归档索引保留。

| 证据 | 可以说明 | 不能说明 |
| --- | --- | --- |
| 确定性软件测试 | 被覆盖的权限、状态流转、来源校验、保存/去重和失败处理符合约定 | 模型已经理解人物、老人受益 |
| 本地模型替身/模拟通知 | 调用数据流、页面流程、账本与回放机制能在夹具中工作 | 真实模型质量、真实发送或送达 |
| 真实模型逐轮原件 | 该版本、参数和输入下实际生成了什么，失败、延迟、费用如何 | 自动推广到其他老人、模型或新版本 |
| 有预先规则的对照实验 | 固定样本与分母上的差异及不确定性 | 真实陪伴、情绪识别或临床效果 |
| C-test 合成会后测量 | 指定虚构脚本下，模型抽取与变化规则是否按预定条件工作 | 认知疾病筛查能力、诊断准确率或真实老人获益 |
| 安装与浏览器复验 | 被测环境中的包可用性和交互行为 | 其他系统也能安装、已经适合生产 |

人物形成、人物/情绪使用、最终回复落实策略是三个问题。事实记忆、预置人物和规则保护
改写不能算成人物学习增益；模型原始回复与最终交付回复需要分别审阅。

对照臂的名称不能证明功能确实生效。必须逐层核对原始候选、产品准入、本人确认和实际
在线注入；若注入为零，就不能把两臂差异解释为该功能的收益或损害。E1b-R 的
[固定结果](E1BR_RESULTS_2026_10_05.md)保留了14候选全拒收、12题说明全空的失败。
修复后的软件正反例只证明对应链路可工作，不补回旧实验曝光，也不替代新模型验收。

规则修订须由未看实现的独立作者先封存自然说法，作者不兼任裁判。独立Codex作者仍属于
模型出题，不是人工或临床标注；将预置标签注入替身只检验软件路径。每个新实验单列
功能实际曝光率及固定分母；低于80%时效果主门不可评，安全、隐私等失败仍需报告。
人物假设未达到working的记录不能算作已影响在线回复，不为展示而降低证据门槛。

2026-10-05首次 E1c 实跑保留原12题、1056个基本调用位置、216个回复评分位置和12个形成
评分位置的分母。实际已发124个基本位置，只有1题完整；第2题的回复是合法 JSON，但
`communication_plan.boundary` 为567字符，超过原上限80，严格校验拒收后停止。
完整测量资格与盲评未启动，结论为不可评（NE），不能把未发的932位置当零分或只报告完整题。
通用短计划提示修复保留原Schema和拒收门，其软件测试不证明新模型输出一定合规。
失败后的提示修改须另版登记；继续使用已接触的题只能作为探索性测试，不能追溯改成原留出结果。

2026-10-06的E1c-v2保留10题、180评分回复和300个A1曝光位置的固定分母。
首段23次有回执请求没有完成任何整题：20份在线正文中19份通过格式校验，另有1次在线、
1次memory和1次reflection正文拒收；另外6轮在本地拒发。HTTP收到正文不等于内容通过。
离线用冻结源重放23份原答，逐请求哈希和26轮实际交付均一致，证实6次拒发为预留输入界超限。
修订价格覆盖和拒发记录属于工程修复；原首答、系统兜底、停止位与费用保持，不据此补出效果成绩。
跨版本续接须另版绑定来源与费用，保留首段已覆盖的30个基本位置及后续已处置位置和各自失败，
不能重发后选较好结果。上文是首段的固定历史结果，不是后续活动的当前总计；续接状态、
已处置/未处置分母、费用与停止原因以 [PROGRESS](PROGRESS.md) 为准。
混合版本须披露每个位置的来源以及已接触的题，不能把新账本当作全新留出实验。
完整生成、测量资格和独立首次标注分别核验；接受某一笔未知费用并保留预留，不等于该笔费用
已结清或未来未知已获豁免，也不能据此宣布模型效果通过。

2026-10-07的[E1c-v2完整结果](E1CV2_RESULTS_2026_10_07.md)保留180回复、50原候选的首次模型标签：
回复主门、形成门和总门均fail；相处说明曝光298/300，其中297个请求收到回执、1个写前失败。
已支持人物假设在834个在线物理请求中均未非空注入，不能将相处说明的使用视作完整人物推理验收。
13个授权类提取风险标签不等于13次真实外发；隔离实验无护理执行记录也不能取消语义风险或证明正式产品权限安全。

同日的S24与D3分别保存固定24题首答和三遍三会话45轮实际交付，见[新版验证结果](VALIDATION_RESULTS_2026_10_07.md)。
S24任务/回复两门失败；D3是单模型描述性首次审阅，没有新增事后总通过线。
D3偏好曝光15/30、适用人物假设0/30，因此两项收益不可评；本地模拟投递及角色扮演家属回执不是真实外发。
随后普通观察与回复来源修补必须用另版材料报告，不能把修补后的软件结果回填到原答或旧浏览器记录。

外部情绪读数、实验注入的合成读数、模型从文本作出的判断分开标注。模拟读数不属于
声学或视觉观测，也不作为会后人物证据；缺少读数或含糊表达不等于中性情绪。
C-test 的虚构日期只用于隔离实验，不能写成真实跨天随访；缺失必填观察字段须标为
不可评，不能当作零观察。修复后的全新测量保留前版失败、未发分母及合计费用。

历史研究尚未证明完整人格效果。旧 r15 保持 **36 份有效评分、1 次中断未知费用、26 题未发**；
未执行/不可评不写零分，不删失败，也不用已知费用代替未知账单。其他历史报告保持原分母和版本。

E1 是作者自建开发题，不能称锁定测试；E2 的影视下一句预测不能证明最佳陪伴回应或老人获益。
CPED 只有满足协议的独立老年样本门后才能报告老年切片，不能用全年龄结果代替。
详见[验证设计](VALIDATION.md)及[CPED 协议](CPED_HOLDOUT_PROTOCOL.md)。

源码修改后不能继承旧模型资格、旧安装或旧浏览器结果。报告需分别写清：工程实现、软件测试、
模拟流程、真实模型实跑、效果验收、发布验收；没有执行的检查就写没有执行。
