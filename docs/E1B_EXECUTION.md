## 授权与总账

唯一正式活动目录是 `artifacts/local/e1b-formal-v1/`，没有更换输出目录或活动 ID 的选项。准备材料的预算状态始终为 `pending`。当前仍须由项目主代理依据用户明确选择确认 12 题、E1b 上限 1 美元和阶段执行授权。

截至本入口登记，历史累计已知费用是 **1.392379172 美元**，另有已接受的 2 笔历史未知。累计停止点仍为 **2 美元**，所以当前可用新余量最多 **0.607620828 美元**。E1b 的 1 美元是实验自身上限，不能重置总账；完成整批不保证。

用户明确费用方案且授权范围覆盖 E1b 后，执行负责人依据已有授权生成独占 `authorization.json`，不要求用户为三个阶段反复批准。其结构由 `authorization_template(root)` 给出：保留规范化项目根与账本归属摘要，将 status、budget_choice、user_limit_usd 和 human_authorization_reference 明确填写；既有累计费用不得降低，总停止点不得提高。每个阶段另需 `<stage>.authorization.json`，字段为 schema=`e1b_stage_authorization_v1`、status=`approved`、stage、registration_sha256、campaign_authorization_sha256；这是已有授权与本次冻结的审计绑定。入口没有自动批准命令，复制授权到另一 checkout 不能新建零费用账本。

`execute` 必须同时显式传入 `--allow-local-env`、`--budget-choice 12_usd1`、独立核对的 `--campaign-authorization-sha256` 和 `--stage-authorization-sha256`。SHA 是解析后的 JSON 按本地 evaluator canonical 规则计算的摘要。文件自称 approved 或机器存在 Key 均不会启动执行。本轮本地开发不运行 execute。

源、协议、能力证据、阶段输入、授权、同一预算绑定及客户端参数核验后，程序只从本机 `.env` 提取 `OPENROUTER_API_KEY`，不加载其他环境变量。实际发送前仍按完整 wire 参数、指定路由、请求字节数加 8192 和最大输出逐笔预留。预留是保守计划界限，不是费用预测或供应商账单保证；不得为了容纳预算漏掉 reflection、降低已登记分母或暗中分批。

## 阶段衔接与失败

三阶段共用 `allowance.sqlite3`。同一运行中所有 app、分支和裁判共用同一 guard 对象；跨进程只有上阶段正常完成、所有费用已知、原账本快照完全一致时才能继续下一阶段。每阶段有固定独占 started 文件，复制登记文件、换输出路径或重新运行都不能绕过。

任何请求未知、失败、保存失败、缺原始提案或不完整标签均停止；保留首次原件，不自动恢复、不选择最好重试。正常预筛完成后可离线交给独立标注者，再准备主阶段。裁判样本在主材料导出时、所有标签出现前固定。裁判首次无效答案仍占原位置，不能换一次正确答案。

## 可核验的结果与仍有限制

每笔持久回执记录实际请求 SHA、操作/会话、模型、路由、usage、阶段和登记摘要；guard 对可见模型正文保存原始与实际客户端返回的 SHA（文本通道去首尾空白，在线 JSON 通道保留原正文），在线另保存解析的回复 SHA，不保存隐藏推理。会后 first 原件与同次 memory、reflection 回执绑定。裁判的合法六标签 JSON 在通过严格白名单后另保存首次原文，以便重新核验 SHA 和标签；无效回应仍只留摘要和错误。资格材料将真实操作回执与保存的交付回复逐项关联，区分未经修改的模型回复、规则修改、纯规则交付及缺失。规则修改属于产品交付表现，不能宣称为模型原始效果。

## 正文失败后的诊断边界（20261003-04）

HTTP 外层解析与正文校验分别记录。收到合法外层和明确费用后，正文 JSON 无效不能再记成网络解析中断；账本保留外层观测、费用和正文 SHA，并只记录固定错误代码。正文检查区分语法错误、重复键、非有限数、顶层类型、缺失/错误/空回复，再调用产品同一完整 Schema 校验器；不修补答案或放宽接收条件。实际调用和当前停止状态见 PROGRESS。

首次失败只留摘要，不能从摘要还原具体坏字段。诊断修复不证明模型格式可靠性已修好，也不构成重开旧活动的理由。后续须有可说明、可测试的调用或格式协议修订，另行冻结完整原分母，保留并结转所有已发生费用；不拼接旧成功回复，不用较好重跑覆盖失败。现入口仍拒绝恢复失败阶段，没有重试或解除停止开关。已有预算选择不需重复询问，改变模型、测量分母或费用边界须另行确认。

生成完成会导出回复与形成盲包，但不会改写 runner 的历史 `frozen:false` 或仅靠自报 `real_model` 宣称效果。`qualification.json` 与生成执行 receipt 只证明生成/传输链，`effect_claim_eligible` 保持 false。形成独立标签、主标签与 40 个联合复核齐备后，可离线运行 `run_e1b.py assess --output <新的结果文件>`；总评会重新核对冻结源码、原登记、只读账本、各阶段前缀、首次标签、形成原件与真实回复资格。完整产品交付门和未经修改的模型回复资格分别解释，不因规则修改改变 4 改善、0 更差的固定产品门，也不把规则保护效果归因于模型。软件替身或假 HTTP 测试不能充当真实模型效果。
