检查方法；源码检查、安装成功、模拟流程、真实效果及允许发布分别判断。

## 软件与故事

在本次候选源码上安装 `.[dev,secure]`，运行：

```sh
python -m ruff check aria examples scripts tests
python -m pytest -q -ra

```

测试只使用合成输入与替身服务，不调用云模型。报告记录源码版本、通过/失败/跳过分母。
旧 E1 执行器绑定旧源码摘要，应拒绝修改后的生产代码；精确列出的历史绑定测试在当前
版本明确跳过，在保留的冻结源码目录另行复验。跳过不计通过，旧效果不迁移到新实现。

浏览器至少三遍完整故事：连续会话、显式会后操作、相处说明提议/确认/撤回、当前说法
优先、本轮实际输入、护理状态、退出/重启、回放无副作用。保留每遍的问题、状态和截图，
不挑最好一遍。默认占位或本地规则提议只验证软件；真实模型故事、录屏、美术/TTS、
失败后的重录须在明确费用与实验授权内执行；已有同批授权不重复询问，也不覆盖旧结果或任意重开闭批。浏览器测试不要求招募老人或采集真人资料。

## 固定87题安全回归

每次准备实际发行候选时，维护者应对同一固定安全集作一次真实模型回归，并保留独立评分。
它与上面的免费软件测试、三遍多会话Demo分开记录；普通提交、安装和远端CI不会自动付费执行。
固定集v1来自四批既有虚构案例，按原封选择为24＋24＋20＋19，共87题、696评分位置。
案例、历史与判据不因新版本失败而替换，旧首答、评分、缺失和费用记录不覆盖。

每次发行的回执须写明固定集版本/摘要、实际源码快照、执行器版本/摘要、模型及供应商、
完整请求装配、该次费用上限及计价证据、唯一运行身份，并分别报告原答/实际交付、
功能曝光、通过/失败/不可评和独立严重安全、隐私及权限结果。曝光不足按原判据记不可评，
可见失败照报；未发送不能记为零费或通过。已知测试集的固定回归不冒充新盲测或真人效果。

标准本地入口 `aria.bench.safety_regression` 默认Max，显式 `--release-profile release_v1` 保留Flash。Max入口已有390项独立本地检查，包括安装后的实际准备、条件安全复核与首答保存。每个最终发行包须包含四份固定JSON并核验完整安装；本地检查和旧Flash结果不能记作当前Max安全87实跑。
默认零付费准备、显式execute及只读verify见[固定安全回归指南](FIXED_SAFETY_REGRESSION.md)。
每次发行须核对正式四JSON及实际安装后的模块/资源来源，执行零Key/零网络默认准备并保留回执；
本页列检查要求，不宣称本次安装已通过。本机任务专用执行器不能冒充标准发行入口实跑。

每次真实回归单独登记该批明确预算、完整适用价格、账户/工作区模式、fresh源/请求装配和
唯一claim；已有该批授权不重复申请，公共入口不继承本地任务的费用许可。总帽保留全部旧hold，
每次新首答重新独评；默认准备零Key/零网络/零模型，不挂远端付费CI。Max固定安全入口保持零响应重试，
固定首答和评分分母仍为87题/696格；每题至多另作一次产品条件安全复核，因此物理请求最多174次。
只有正面证据证明尚未写出应用数据的特定TLS准备失败，可在同一原物理请求和期限内额外建连一次；
它不增加物理请求位置，也不重试响应。显式旧Flash仍按其旧合同最多87次、零恢复执行。
固定安全批不继承私有实验或普通聊天的无答后继续新输入许可，不补跑已关闭批次。
Max普通入口的四角色限额见本地指南；任务专用执行器资格不能迁移为普通入口资格。

本版正式虚构案例及原判据副本已在696格独评封存后独立导出并核完整性、来源和公开材料范围。每次发行仍须绑定其固定版本及摘要，不随结果选择或改写素材。
软件检查、中性夹具和说明命令不证明真实安全结果，也不预先授权公开封题、模型原件或账务资料。

## 最终候选与发行范围

先按最终逐文件推广清单应用已独立验证的候选，核应用前后摘要；保留原工作区修改及历史原件。
运行期冻结依赖的根源码不得边跑边改。README只陈述实际结果，最新状态仍链接PROGRESS；
各真实请求与源码快照逐项绑定，混合来源实验不能冒充最终安装包上的完整模型复测。

隔离安装核验用的候选可能缩减 `MANIFEST.in`，不能直接作为完整发行清单。最终source ZIP和sdist应保留
`docs/` 中已列入范围的说明、`scripts/build_minimal_release.py`、`scripts/check_release_install.py`、
`scripts/prepare_model_policy.py`及既有冻结实验的必要入口。不得覆盖根完整清单造成这些文件遗漏。
wheel与sdist均须保留 `aria/bench/cases/fixed_safety_v1/` 的 `manifest.json`、`inputs.json`、
`references.json`、`protocol.json` 四份既有资源，逐件核字节摘要；不能因安装简化而换题或漏题。

最终推广后重做完整包的来源与内容检查：普通 `aria-web` 默认Max；`aria-model-policy`的显式Max参数、
三个元数据输入、预览零Key/零模型、四职责持久限额、120秒间隔与90/240秒期限均与安装产物一致。
验证清除体验资料会擦除本地模型可见正文及流片段，保留最小核账/防重发状态并阻止旧在途正文写回；
这不删除实验历史原件，也不清空未知费预留。已有软件通过报告仅适用于其绑定源码，不继承为新版通过。

## 源码 ZIP

```sh
python scripts/build_minimal_release.py --check
python scripts/build_minimal_release.py --output dist/candidate-source.zip
python scripts/build_minimal_release.py --verify dist/candidate-source.zip
```

已有输出不能覆盖，另选新文件名。构建只读取明确白名单，检查路径、大小、内容和
SHA-256，扫描后源码变化会拒绝打包。`RELEASE_MANIFEST.json` 是完整性记录，不是签名、
安全证明或效果证据；范围以脚本及包内 `RELEASE_SCOPE.md` 为准。

不包含真实 `.env`、运行资料、Git 历史、私人实验输出、下载语料或媒体；`.env.example`
只是示例配置。旧占位截图/视频留在本机，新的公开画面须独立审查。

## wheel / sdist 与安装

构建工具安装可能联网；以下步骤不上传包。使用新的输出目录，避免混入旧候选包：

```sh
python -m pip install build twine
python -m build --outdir dist/candidate-packages
python scripts/check_release_install.py --dist-dir dist/candidate-packages
```

安装检查脚本在 Windows/Linux 使用对应虚拟环境路径，要求恰好一个 wheel 和一个 sdist，
逐个检查资源、许可文件、私有目录排除及包摘要，并执行严格元数据检查。两个新环境分别
安装 wheel/sdist，核对依赖、CLI、隔离导入来源、实际本机 HTTP 页面、三次预览会话、
护理登录/老人范围/撤回，以及读取旧记录无新动作。固定安全四份JSON也须进入wheel/sdist，
安装后核实际 `aria.bench.safety_regression` 来源并由 `load_suite` 验证87/696与素材摘要。
完整默认prepare另按固定安全回归指南在安装环境执行，不以仅导入成功代替。原型模型、真实通知和 `.env` 读取
始终关闭。记录保存在新运行目录的 `result.json`；失败保留目录，不覆盖旧证据。

离线本机复用已安装依赖时，明确使用：

```sh
python -m build --no-isolation --outdir dist/local-packages
python scripts/check_release_install.py --dist-dir dist/local-packages --work-dir artifacts/local/install-check-new --reuse-local-dependencies
```

这是安装产物检查，报告标记 `local_reused_not_cold`，不能称为陌生机器联网冷安装。
`.github/workflows/test.yml` 配置 Windows/Linux × Python 3.10/3.12，全量软件测试及两个
干净安装环境；配置已写入不代表远端四组已通过。只有实际 CI 回执能证明远端运行结果。
首发最低版本不因本机使用较新 Python 而自动验收。

### 当前本地版本的证据检查项

本地版本由普通Max默认、四角色费用保护、偏好与反思机械修补、固定安全入口、本人新输入恢复及v6完整格式失败隔离组成。公共恢复v2及只增加正面TLS前失败处分的v3均已另作独立边界复核，旧v1的磁盘/内存不一致失败保持。

- 恢复候选的最终独立复核、冻结源码与普通安装后检查；原失败与未知费用预留均保持。

- 最终源码ZIP、wheel和sdist的字节绑定、固定四文件原SHA、所有公开链接、范围与隐私审查。
