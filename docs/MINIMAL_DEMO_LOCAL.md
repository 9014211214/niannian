# 本地使用

[当前进度](PROGRESS.md) · [产品与架构](PRODUCT.md) · [安全与隐私](../SECURITY.md)

## 安装和启动

需要 Python 3.10+，只用虚构内容。安装依赖可能联网，不执行模型。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\aria-web.exe --minimal --port 8081
```

Linux 使用对应虚拟环境路径：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/aria-web --minimal --port 8081
```

打开终端打印的本机地址。默认不读 `.env`，环境中有 Key 也不会启用模型、媒体或真实通知。
占位回复明确标记为本地预览，不能当成真实陪伴或人物学习。

## 连续会话与会后整理

1. 开始会话，选填、修改或自由输入老人侧话语。点击发送只提交当前话语，不把未来台词、
   作者心理解释或尚未透露的背景提前交给 Agent。
2. 每次建议约五轮；“结束并封存”保存原话。下一会话继续同一虚构人物，实际时间不变造。
3. “明确启动会后整理”是单独操作。本地预览不运行模型；真实模式每次处理最早一个待整理
   会话。memory 整理事实，reflection 独立审核原会话、旧假设及证据。
4. 侧栏区分事实、本人相处说明与人物假设，显示来源、范围、反证和纠正。候选未升格、
   无变化都正常；置信不是准确率。旧会话的普通档案侧栏标的是当前档案，不冒充过去时点快照。

本人原话支持的相处说明先是待确认，确认后才进入后续在线输入；可选择不记或撤回。
撤回、取代后保留出处和变化记录，后续输入不再使用。相处说明不授予分享、提醒或通知权限。
默认预览中，“本地规则提议相处说明”是封存后的显式演示操作，不调用模型、不生成事实或
人物假设，也不完成会后整理队列；提议带规则来源。真实模式由手动会后 memory 调用提议，
仍需原话核验和本人确认；提取/确认的软件验证不能代替模型效果验证。

“本轮依据”保存当次真正进入请求的短上下文、相关事实、适用且有依据的人物假设、已确认
说明和有限护理状态。原会话出处不一定进入本轮输入，页面分开标记；不展示隐藏推理。
缺少旧快照时明确说明不可恢复，不用当前档案补造过去依据。回放读取原记录，不刷新依据。

闲置、断开或退出只封存；不会自动启动会后模型。模型失败和保存结果不明会停止后续调用，
相同请求 ID 不再次发送，也不偷偷替换成预写回复。

## 可选情绪读数与记忆变化记录

EM-1 允许接入方随当前文字请求显式提供 `external_emotion`，包含 `label`、`confidence`、
`modality`、`source` 四个字段。没有输入就不增加情绪提示；`unknown` 表示不明。
页面把读数标成“外部情绪读数，可能有误”，本人原话、拒绝和纠正优先；它不进入人物假设、
认知变化或医疗/通知升级证据。接口不会自行调用声学、视觉或情绪模型，也不声称观察到了声音或表情。
普通 Web 拒绝合成读数；专用 Python 实验能力对象绑定独立目录和虚构档案，实验结果显著标记。

“记忆与日常变化提醒”默认关闭。本人在页面开启后，明确启动会后整理才会抽取授权期间的本人
原话；普通聊天档案和人物反思不会把这些敏感记录当人物证据。本人可查看、逐条删除、关闭并选择
是否清除观察。校准和提醒规则只比较本人先前记录；不出病名、分数或诊断，不自动通知家人。
当前本地预览不调用会后模型，因此开启按钮不等于已抽取观察或证明功能有效。
详见 [C1 设计与边界](COGNITIVE_CHANGE.md)。

这里的“本人”是本机虚构人物 `fictional-chen` 的操作身份：持有体验凭证的人可代入该角色；
它不提供真实老人的身份核验。护理后台不能代本人开启或修改这些观察。不要输入真人健康资料。

## 舞台、字幕与回放

舞台动作只是表现；字幕来自实际交付回复，保留占位、真实生成或规则接管的来源。
支持暂停、文字视图、接管输入和保存回放；暂停不能取消已经提交的请求。本版不提供 TTS。
回放只读已取到的文字，不能重新调用模型、创建提醒或通知；动画不当感知证据。

旧截图和 60 秒预览来自本地占位流程，原件保留在本机，首发源码包不分发。
旧预览由 120 张截图按 2 fps 合成、经过剪辑、无音轨；不代表真实 Agent 效果或实时延迟。

## 护理员与模拟护理

首次在私有终端创建护理员并启动服务：

```powershell
.\.venv\Scripts\aria-web.exe --minimal --care-setup-admin caregiver --port 8081
```

按提示两次输入至少 12 字符密码；无默认密码。账号分配给虚构老人 `fictional-chen`，
已有账号不会被重置。以后省略设置参数，在 `/care` 登录；服务端检查负责老人范围。
Linux 对应命令为 `.venv/bin/aria-web --minimal --care-setup-admin caregiver --port 8081`。

- 在陪伴页或后台表单创建一次性/每日提醒，填日期、时间、时区和未确认宽限。
  只支持 `Asia/Shanghai`、`UTC`。聊天提要求不等于已创建，必须明确保存并核查状态。
- 老人可以确认收到、拒绝、延后或取消；护理员不能代老人确认。超时只是“未确认”，
  不能推断没吃药或遇险。
- 添加虚构联系人，指定提醒、未确认触发、仅提醒状态的分享范围和有效期，可撤回。
  这是模拟授权，不含真实收件地址；聊天全文与人物假设不外发。
- 有效规则满足时自动记入本地通知台账，无须每条再批。区分排队、受理、送达、家属确认
  和人工跟进；模拟记录不等于真人收到。跟进任务记录处置后关闭。
- 撤回、取消或老人回应阻止尚未执行的通知；结果未知不自动重发。已发送内容不能收回。

护理相关回合读取本人最近有限记录，最多三条提醒及相应有限期次、授权、通知与跟进状态。
遗漏数量和读取失败可见；失败不当作没有记录。快照不含姓名/地址、通知正文、跟进备注或
登录资料，真实模型模式会将该快照随本轮输入发送。每轮保存当时依据，回放不刷新旧快照。
这是关键词触发的有限只读参考，不赋予聊天写操作能力，也不是新人物证据或成功回执。

护理调度在服务运行时独立继续，包括关闭聊天或回放时；停止服务后暂停。错过的每日提醒
不会补记为送达。首发仅模拟通知，CLI 没有真实外发开关。

## 数据、删除与失败

默认根目录 `data/minimal_demo`，可用 `--minimal-data-dir` 指定独立根目录。预览与真实模式
分别在 `local_preview`、`live`，不要指向真实老人资料。只支持单服务实例。

“清除本次体验资料”删除当前模式的对话、档案、队列和本虚构老人的护理记录，保留护理
账号/分配与真实模式调用台账；不清其他模式、备份或云端已接收的数据。
`ARIA_PROFILE_KEY` 配合 `secure` 依赖可加密档案及回放，**不加密护理库与调用台账**。
原话整理队列每会话最多 120 轮/60,000 字符、保留 24 小时；完整回放保留至主动清除。

## 显式启用文字模型

先查看 [.env.example](../.env.example)，仅配置其中所需的文字模型与可选档案加密字段，
真实 Key 只放本机 `.env` 或环境变量，不放聊天、截图或 Git。默认启动仍不会读它。

真实模式增加 `--enable-model-calls`，同时必填 `--model-max-requests`、
`--model-stop-cost-usd` 和 `--model-reservation-policy`。次数为 1–10000 的整数，金额为正数 USD；
没有默认消费金额，参数或策略错误会在读取凭据前拒绝。启用前核对服务商、模型、价格与可接受预算。

先将公开模型列表和两个指定模型的端点元数据分别保存到本机 JSON。策略生成器只读取这些文件，
不下载资料、不读取 Key、不启动模型；资料的来源、读取时间和是否仍适用于本次执行由执行人核对。
三份输入分别对应 OpenRouter 的 `/api/v1/models`、
`/api/v1/models/qwen/qwen3.7-flash/endpoints` 和
`/api/v1/models/anthropic/claude-sonnet-5/endpoints`。不要用包含账号或凭据的响应代替公开资料。

在项目根目录执行以下离线命令（先把三份文件放到对应位置）：

```text
python scripts/prepare_model_policy.py --models-json artifacts/local/model-metadata/models.json --online-endpoints-json artifacts/local/model-metadata/online-endpoints.json --offline-endpoints-json artifacts/local/model-metadata/offline-endpoints.json --output artifacts/local/model-policy.json
```

输出策略及同名 `.proof.json` 核对记录；已有文件不会覆盖。不支持参数、未知价格档位或端点不符
都会拒绝生成。生成成功仅证明保存资料符合本地检查，不是已发送请求或真实兼容性验收。

确认预算后，在原启动命令中增加以下参数；把 `N` 和 `USD` 换为本次明确接受的次数与金额：

```text
--enable-model-calls --model-max-requests N --model-stop-cost-usd USD --model-reservation-policy artifacts/local/model-policy.json
```

策略文件或密钥的存在都不会自动打开模型；预览模式也不能仅带限额参数开启调用。

仓库默认在线 Qwen3.7 Flash，会后 Claude Sonnet 5 分别承担 memory/reflection。
默认在线 `v1`＋`mode_v1`；`ARIA_ONLINE_DECISION_VERSION=online_turn_decision_v2` 与
`ARIA_DELIVERY_BLOCK=profile_v1` 仅供显式实验，不代表已通过效果验收。
最小入口在线使用 JSON 正文返回，完整决策 schema 随提示发送，响应经本地严格校验；
不发送工具强制选择和并行工具字段。通用客户端保留旧 native 模式供旧实验复现，会后两次
调用保留各自正文职责。生产装配没有直接套用旧 E1 请求字节，真实新版效果需另测。
JSON 正文模式不保证每个字段都符合长度或枚举约束。提示要求当轮相处计划简短，但最终仍以
本地严格校验为准；格式失败不会截短后冒充成功。诊断只保留约束类型与固定字段路径，不复制
回复内容或模型生成的未知字段名；实验入口也会保留这些脱敏信息，原失败账本不回填改写。
最小入口在线输出上限固定为 1024 token，Sonnet 会后职责保留各自原默认上限。
普通文本请求同样保留供应商、隐私与输出上限约束，不因没有 JSON 返回要求而放宽。

三个职责共享持久调用台账；刷新、重启或清除聊天不恢复额度。失败/费用未知/结果未知
停止后续调用，保留封存、读取和独立护理。旧 live 有对话却无账本时拒绝从零记费。
调用台账还绑定模型和完整返回合同；旧已启用 live 的合同与新版不同时会安全拒绝。
须核对旧费用并明确迁移后才能再次启用，目前没有自动迁移脚本，不能换目录或删账绕过。
发送前按已冻结价格、完整请求字节与额外模板预留量、输出上限核查预算；收到回执后核对实际
模型、供应商、token 与费用。未知结果保留预留额并停发，保存失败不盲重试。
**这是本地发送前预算保护，不是供应商账单硬帽**；预留 token 是保守规划量，不冒称精确计数，
也不约束其他目录或工具。不要换目录或删账绕过安排。正常 3×5 轮最多可安排 15 次在线＋6 次会后，
只是次数建议，不是金额报价或失败后的补跑授权。

## 本地验证

安装 `.[dev,secure]` 后运行 `python -m pytest -q -ra`；本地测试使用固定夹具，不调用云模型。
绑定旧实验源码摘要的测试明确跳过并说明使用冻结快照复验，跳过不计通过；当前产品测试
与旧实验复验分别报告。Windows/Linux、Python 3.10/3.12 的 CI 配置不等于已经远端运行。
源码检查用 `python scripts/build_minimal_release.py --check`。
[打包与发布步骤](MINIMAL_RELEASE_CHECKLIST.md)和[证据边界](EVIDENCE.md)说明这些检查的限制。
