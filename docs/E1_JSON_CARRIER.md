# E1响应载体修订（T7.5）

当前状态只见[PROGRESS](PROGRESS.md)。这是T7.4实际兼容之后的前瞻修订；不修改已执行的请求、失败、费用、冻结原件或参考答案。

## 实际问题

T7.4选择当前端点支持的`tool_choice=auto`，实际11项返回单次工具调用，第12项返回正文JSON。auto允许这两种载体，而接收端仍只接受工具，故第12项在解析前被拒收。该失败保留；全部12次已知费用0.00171618美元计入原E1预算，不能把HTTP成功或本地重解析写成原实验成功。

## 新接收合同

实际请求完全复用T7.4：提示、题目、模型、供应商、工具参数schema、auto、无parallel、reasoning关闭、禁止fallback、require_parameters与data_collection=deny均不变。全部204位置/65实际请求SHA和原T6祖先SHA保持；不新增模拟老人或模型探针。

新接收端只接受互斥的两种真实载体：空正文且恰好一次原生`aria_turn_decision`工具调用（`native_tool`），或无工具调用且正文为完整JSON对象（`content_json`）。回执envelope不改，不新增或伪造tool_calls。两者均按请求中的原工具parameters校验必填、类型、枚举、长度、数值和额外字段，然后经过原生产决策解析与交付护栏。

Markdown、普通文本、混合载体、多个工具、错误工具、重复JSON键、隐藏推理、不完整字段、截断、usage/费用缺失、超预算及保存失败仍拒收并持久停发；不修补或补写模型答案。结果逐项记录实际载体、协议版本和字段schema SHA，不把字段声明当真人观察或授权。
