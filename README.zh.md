# Aria

[English](README.md) · [当前进度](docs/PROGRESS.md)

Aria 是一个本地老人陪伴原型：理解他希望被怎样对待，保留理解的依据，允许他纠正，
并在回应和行动时尊重他的选择。陪伴、人物理解与必要护理在同一个 Web 中衔接。
DISC、Big Five、依恋等是沟通理解框架，不是诊断或永久标签。

## 启动

需要 Python 3.10 或更新版本。在项目目录执行，Windows：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\aria-web.exe --minimal --port 8081
```

Linux：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/aria-web --minimal --port 8081
```

打开终端显示的本机地址。默认使用有明确标记的占位回复，不读 `.env`，不调用模型，
不发送真实通知。只输入虚构内容；安装依赖可能需要联网。

需要护理后台时，在启动命令后增加 `--care-setup-admin caregiver`，在私有终端提示中
设置密码。没有默认密码，也不要把密码写进命令或聊天。

真实文字模型模式还须同时提供 `--enable-model-calls`、`--model-max-requests`、
`--model-stop-cost-usd` 和 **`--model-reservation-policy`**。先用
`scripts/prepare_model_policy.py` 从已保存的公开模型/端点资料离线生成价格预留策略，
具体文件与命令见[本地指南](docs/MINIMAL_DEMO_LOCAL.md#显式启用文字模型)。有 Key 或策略文件
不会自动启用模型。发送前预留费用，结果未知即停发；它不是供应商账单保证。

## 第一版本保留什么

- 同一虚构人物的连续会话，事实与人物假设分开，展示原话来源、范围与纠正。
- 显式启动的会后事实整理和人物审核；关闭或闲置只封存。
- 本人确认的相处说明，与推断假设分开，可撤回；每轮保存实际输入依据。
- 轻量舞台、实际回复字幕、可接管输入和保存回放。
- 护理员登录及老人范围、一次性/每日提醒、确认/拒绝/延后/取消、授权撤回、
  模拟通知回执及跟进关闭。
- 明确启用后才使用的文字模型，以及持久调用记录、费用未知和失败停止保护。
- 可选的当轮外部情绪读数，标明可能有误；缺失不加提示，不明不当作平静。
- 默认关闭、由虚构本人开启的记忆与日常变化记录；可看原话、删除或关闭，不作疾病诊断。

在线默认 `v1` 协议和 `mode_v1` 四档表达；`v2` 推演和 `profile_v1` 画像仍是显式实验。
有授权的转达体验和真实 Agent 短片尚未完成；实现与版本验收结果以进度入口为准。

首发通知使用接口与模拟通道。摄像头、声学情绪、ASR/TTS、Omni、全双工、硬件、
其他产品场景和旧大型研究平台不在本版本中。本原型不是可直接投入机构使用的护理系统。
外部情绪接口不会启动传感器或情绪模型；合成读数只能在独立 Python 实验目录中使用并显著标记。
本机体验凭证的持有人可以代表虚构本人操作，这不是实际老人的身份核验；护理员权限不代替本人操作。
